# stir-crazy-testpages

Public test pages for the Stir Crazy HomeView device test (see `docs/SPIKE-HomeView.md` in the private app repo). Synthetic recipe only; nothing private goes here.

Served by GitHub Pages at https://petergca.github.io/stir-crazy-testpages/

- `full.html`: visible recipe + schema.org/Recipe JSON-LD
- `jsonld-only.html`: JSON-LD + a title, almost nothing else
- `control.html`: visible recipe, no structured markup
